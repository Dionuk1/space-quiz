# Space Quiz

Space Quiz is a lightweight, 10-question astronomy practice game. It runs entirely in the browser and gives immediate feedback, progress tracking, and a final score without an account, server, build step, or external dependencies.

## Run locally

Open `index.html` directly in a browser:

```text
file:///path/to/space-quiz/index.html
```

No package installation or local server is required.

## GitHub Pages

The site is deployed automatically from the `main` branch by the workflow in `.github/workflows/pages.yml`. The workflow uploads the repository as a static Pages artifact and publishes it with GitHub Pages.

## Project files

- `index.html` — the complete app, including markup, styles, quiz data, and behavior.
- `PRODUCT.md` — product constraints and audience.
- `DESIGN.md` — visual and accessibility direction.
